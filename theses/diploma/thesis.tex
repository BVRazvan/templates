\begin{sinopsis}
Unikernelul reprezintă un sistem de operare de tip librărie, creat special pentru a putea executa o singură aplicație, fără alte funcționalități inutile. \\ \\
Lucrarea se învârte în jurul conceptului de unikernel în cadrul Unikraft, un proiect open-source ce dezvoltă un mediu pentru crearea și folosirea facilă a acestora.
Așadar, de-a lungul lucrării sunt prezentate două metode de a integra un server de OpenArena în cadrul Unikraft. OpenArena este un joc open-source scris în C și apărut în 2005. \\ \\
Prima metodă, numită intuitiv modalitate de portare binară, pune în evidență capacitatea Unikraft de a crea astfel de sisteme de operare plecând de la fișierul de tip executabil al serverului. \\ \\
    Cea de-a doua metodă, numită modalitate de portare nativă, pune accent pe instrumentele care stau la baza acestui proiect, permițând o înțelegere amplă a ceea ce se întâmplă. \\ \\
În plus, lucrarea prezintă și procesul de a crea din server-ul de OpenArena o librărie specifică Unikraft, ceea ce reprezintă unitatea de bază într-un unikernel, folosită ulterior cu același scop ca mai înainte.
\end{sinopsis}

\begin{abstract}
The unikernel represents a library operating system, specifically created to run a single application, without unnecessary functionalities. \\ \\
The thesis revolves around the concept of unikernels in Unikraft, an open-source project that develops an environment for the easy creation and use of unikernels. The paper presents two methods for integrating an OpenArena server within Unikraft. OpenArena is an open-source game written in C and released in 2005. \\ \\
The first method, intuitively called binary compatibility mode, highlights Unikraft's ability to create such operating systems starting from the executable file of the server. \\ \\
The second method, reffered to as native compatibility mode, focuses on first-principle tools used in the project, allowing for a broader understanding of what is happening under the hood. \\ \\
Additionally, the paper presents the process of converting the OpenArena server into a Unikraft-specific library, which represents the basic unit within a unikernel, used subsequently for the same purpose as before.
\end{abstract}
